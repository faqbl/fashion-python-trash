TicTacToe is a traditional chess game.It requires 2 characters playing in a 3×3 board and using 'X'&'O' as pieces.The first one who make its pieces 3 in row,column,or diagonal wins.
Now we fight against an agent,and use RPS game to decide who's the first.Agent 'gestures' by random function to ensure the randomness and fairness.
TicTacToe will be always tie game for masters.You can never win the agent so don't be discouraged.
